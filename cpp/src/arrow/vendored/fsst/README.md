# Vendored CWI FSST

This directory contains the FSST8 implementation from
https://github.com/cwida/fsst at commit
`89f49c580c6388acf3b6ed2a49e1bfde6c05e616`.

The sources are unchanged except for trailing-whitespace normalization.
Parquet-specific serialization and validation live in
`cpp/src/parquet/fsst_internal.cc`.
